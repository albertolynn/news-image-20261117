A Node program that draws a one-page newspaper summing up the world news of Tuesday 17 November 2026 — masthead with the date, a lead story, four panels and a news ticker — entirely in code (its own PNG encoder and vector stroke font, no image assets), and writes it as a 1024×1024 PNG.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
